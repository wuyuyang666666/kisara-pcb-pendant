# v13 · 等比缩小 0.5 cm（长宽比例不变）

> **一句话**：板宽 56 → **51 mm**，总高 63.5 → **57.83 mm**，缩放系数
> `K = 51/56 = 0.910714286`。所有 12 层图元逐点等比，图案、颜色、层叠、极性一个没动。

---

## 一、你要的数字

| 下单页「板子尺寸」 | 原 v12 | **改后 v13** |
|---|---|---|
| 宽（第一个框） | 5.6 cm | **5.1 cm** |
| 高（第二个框） | 6.35 cm | **5.78 cm**（5.7830 四舍五入） |

`6.35 × (5.1 / 5.6) = 5.7830` → 长宽比 `5.1 / 5.78 = 0.8824`，
与原来 `5.6 / 6.35 = 0.8819` 一致（四舍五入误差 0.0005，板框文件里是精确等比）。

> 若你想的是「把**高**减 0.5 cm」而不是宽：高 **5.85 cm**、宽 **5.16 cm**
> （`5.6 × 5.85/6.35 = 5.159`）。这是另一组数，别和上面混用。
> 本文件按第一组（宽 5.6→5.1）生成。

---

## 二、⚠️ 只改下单页这两个数字，实物不会变小

**这两个框是系统从 Gerber 的 `GKO` 板框层自动解析出来的**，不是生产参数：

1. 板厂按 `GKO` 轮廓锣外形。GKO 还是 Φ56 mm，出来的板子就还是 56 × 63.5 mm，
   数字改成 5.1 × 5.78 只是让「申报尺寸」和「文件尺寸」对不上；
2. 多数情况下该框是只读 / 提交时被重新解析覆盖；即使能填，
   尺寸不符容易触发 **工程确认（EQ）** 或资料不符提示，免费券订单最怕引入人工环节；
3. 挂孔、金环、丝印、6 层铜的坐标都在文件里，改框一个都动不了。

**要真的变小，只能换 Gerber 文件** —— 已做好：`build/Kisara_Pendant_6L_ENIG_v13.zip`。
上传/导入这份，下单页会自动变成 **5.1 × 5.78 cm**（或 5.1 × 5.783）。

## 五、换成 v13 后要重做的事（其余全部沿用）

1. **EDA 工程要重新导入一次** v13 的 zip（原来那份工程里还是 56 mm 的板框）。
   G2PCB 图层设置、G5 处理、「保存为 EDA 工程」按 `README_v12.md` 第三节原样走一遍。
2. 从 EDA 重新导出 Gerber 时，依旧**必须勾「板框层」+「钻孔文件」**（挂耳和挂孔全靠这两层）。
3. 下单页「指定层压顺序」仍按 v12 那张 **L1 GTL / L2 G1 / L3 G2 / L4 G3 / L5 G4 / L6 GBL**
   表填；尺寸框会自动显示 5.1 × 5.78，不要手改。
4. 其余下单参数（FR-4 TG135 / 6 层 / 5 片 / 1.6 mm / 绿阻焊 / 白字符 / 沉金 1U /
   无阻抗 / 加嘉立创客编 / 确认生产稿不需要 / HDI 无）**一个都不用动**，结算页重新点券。

> 不想重走 EDA 导入的话，还有个更省事但**不推荐**的做法：让挂件维持 56 mm，
> 只在钥匙圈上换更短的连接件 —— 但那不解决「板子本身太大」。
